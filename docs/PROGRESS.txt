CURRENT TASK / REVIEW FINDINGS
The user is passing these findings to Grok. Fix completion is not yet reviewed.
1. Consumer shutdown: try_pop is not protected by callback inflight tracking.
   Do not free the queue while a consumer can still access it.
2. Failed-removal ownership: a surviving hook still references the Observer.
   Leaking the queue in the destructor does not preserve the Observer object.
   Enforce retained object/callback-state lifetime before real hooks exist.
3. Capacity one: installation accepts it, but the sequence-number queue loses
   records without counting drops. Codex reproduced two pushes followed by
   no readable record and zero drops. Reject capacity < 2 or implement it.
