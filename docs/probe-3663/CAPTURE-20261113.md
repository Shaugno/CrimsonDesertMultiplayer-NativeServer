## Hypotheses

Late completion of the start export is plausible: the controller recorded a
timeout, and the session file contains a ready block. The archive does not
measure which of those became durable first, so late completion is not an
observation. The start return itself was not collected.

The repeated 181-byte send rows are consistent with a periodic client send
while the character was standing. They are not evidence that any byte is a
position, heading, or actor id. Receive bytes may still be pre-transform.
